# AI Usage Policy

Maggie is a terminal for running Claude Code, and it is built with Claude Code.
AI assistance is welcome in contributions, on these terms:

- **You understand what you submit.** You must be able to explain every change
  and how it interacts with the rest of the code without an AI tool at hand.
  If you can't, keep working on it until you can.

- **You say so.** State in the pull request which tool you used and how much of
  the work it did. There is no penalty for "all of it"; there is for hiding it.

- **You review before you submit.** Generated text and code tend to be verbose
  and to include things that don't belong. Trim them. Issues and pull request
  descriptions are read by a person; write them for one.

- **Media is fine.** Icons, images and sounds may be AI-generated. The app icon
  is.

This policy replaces Ghostty's for this repository. Contributions that go to
Ghostty itself follow
[Ghostty's policy](https://github.com/ghostty-org/ghostty/blob/main/AI_POLICY.md).
